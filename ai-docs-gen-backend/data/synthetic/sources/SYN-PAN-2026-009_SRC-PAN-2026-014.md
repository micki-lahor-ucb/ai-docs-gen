DOCUMENTO SINTÉTICO PARA EVALUACIÓN ACADÉMICA — NO CORRESPONDE A UN CASO REAL

- case_id: SYN-PAN-2026-009
- source_id: SRC-PAN-2026-014

En la gestión 2018, se documentó el robo de una computadora portátil (equipo de oficina) desde la sala de juntas principal. El incidente ocurrió durante un corte general de energía eléctrica, aprovechando la desactivación temporal de las cámaras de seguridad. Se levantó una denuncia formal ante las autoridades competentes, presentando las facturas originales de compra.

La aseguradora cubrió el costo total del equipo sustraído tras verificar que los protocolos de seguridad de la institución eran adecuados, pero vulnerables ante apagones prolongados. A partir de este evento, se instalaron fuentes de alimentación ininterrumpida para todo el circuito cerrado de televisión.
